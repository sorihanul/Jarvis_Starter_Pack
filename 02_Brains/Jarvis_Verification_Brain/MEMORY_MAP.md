## 읽기 원칙

- 대상의 route surface를 먼저 찾는다.
- 검증 기준 파일이 있으면 기준을 우선한다.
- 원소스와 로컬 사본이 있으면 둘의 역할을 먼저 분리한다.
- 실제 실행하지 않았으면 runtime 검증이라고 말하지 않는다.
