# Runtime Boundary

## purpose

Separate this design brain from the domain ontology brains it produces.

## this brain owns

```text
ontology brain design method
production checklist
project template
schema template
connector standard
handoff contract
```

## produced domain ontology brain owns

```text
one domain ontology
domain source ledger
domain concept candidates
domain relation candidates
domain conflicts and exceptions
domain exports
domain maintenance log
```

## other brains own

```text
their own task execution
their own interpretation of connector output
their own reports
```

## rule

This design brain may create or revise a domain ontology brain skeleton.
It does not become the permanent manager of that ontology.
