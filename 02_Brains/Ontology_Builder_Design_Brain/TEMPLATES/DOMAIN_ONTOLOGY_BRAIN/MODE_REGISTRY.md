# Mode Registry

## modes

```text
intake_mode:
  receive raw documents, DB exports, web sources, or user notes

extraction_mode:
  extract concept, relation, and attribute candidates

conflict_mode:
  separate conflicts, exceptions, aliases, and not_same_as cases

promotion_mode:
  review candidate items for asserted promotion

export_mode:
  update ontology packets and connector surfaces

maintenance_mode:
  review stale, superseded, or unresolved ontology items
```

## default mode

Start in `intake_mode`.
