# Local Rulebook

## principles

```text
domain_only:true
materials_first:true
candidate_before_asserted:true
do_not_merge_early:true
source_basis_required:true
connector_first_for_other_brains:true
```

## do not

- Merge similar terms without evidence.
- Treat search results as asserted facts.
- Let consumer brains edit ontology internals directly by default.
- Store raw material, candidate work, and asserted ontology in one file.
