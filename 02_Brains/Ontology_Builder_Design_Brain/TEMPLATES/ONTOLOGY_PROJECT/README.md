# Ontology Project Template

## purpose

Use this project template inside a produced domain ontology brain.

## copyable starter files

This folder is a minimal copyable ontology project skeleton.

Copy it into:

```text
<Domain>_Ontology_Brain/PROJECT/
```

Then replace `<Domain>` placeholders.

## project rule

```text
Raw material, candidate work, promoted ontology, exports, and indexes stay separate.
```

## minimum viable project

```text
PROJECT/
  README.md
  SOURCE_LEDGER.md
  WORK/
  ONTOLOGY/
  EXPORTS/
  INDEX/
```

## use

Create the full layout when the domain will persist.
Use the minimum layout only for small trial ontologies.
