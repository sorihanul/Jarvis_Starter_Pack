# Ontology Builder Design Brain START HERE

## identity

This brain designs and produces domain-specific ontology brains.

It does not own every ontology.
It creates the brain, project template, schema, connector, and export contract needed for a domain ontology brain to manage one ontology.

## use when

Use this brain when the user wants:

```text
domain ontology brain design
ontology project workspace design
AI-usable ontology pack design
ontology export/connect surface design
ontology brain production from documents or DB material
```

## do not use when

```text
one_time_concept_list:true
simple_summary:true
single_domain_ontology_maintenance:true
full_graph_database_implementation:true
```

If a domain ontology already exists, hand off to that domain ontology brain instead of redesigning it here.
