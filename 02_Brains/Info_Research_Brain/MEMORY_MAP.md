- `NOTES/SOURCE_LEDGER.md`
- `NOTES/FINDINGS_INDEX.md`

## External Source Memory

사용자가 주는 로컬 파일, 링크, 웹 자료, 논문, 공식 문서다.

이 브레인은 외부 자료를 기억으로 복사하지 않는다.
출처, 핵심 주장, 확인 상태, 다음 읽기 경로만 남긴다.

## Do Not Read By Default

- 대량 원문 전체
- 오래된 로그 전체
- 출처가 불명확한 스크랩 묶음 전체
- 사용자 요청과 무관한 도메인 자료

## 읽기 원칙

- 먼저 route surface를 찾는다.
- route surface가 없으면 파일명, 날짜, 출처, 목적 기준으로 작은 샘플을 고른다.
- 큰 자료를 읽었으면 무엇을 읽고 무엇을 건너뛰었는지 결과에 남긴다.
