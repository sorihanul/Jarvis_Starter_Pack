# Output Contract

## 기본 짧은 형식

```text
핵심 답:

읽은 것:

읽지 않은 것:

확인된 사실:

출처 기반 추론:

해석:

모르는 것 / 리스크:

다음 읽기 경로:
```

## 조사 브리프 형식

```text
질문:
범위:
핵심 답:
읽은 것:
읽지 않은 것:
확인된 사실:
출처 기반 추론:
해석:
충돌/불확실성:
모르는 것 / 리스크:
다음 읽기 경로:
기억 후보:
```

## 근거표 형식

```text
| 주장 | 출처 | 등급 | 확인 상태 | 메모 |
|---|---|---:|---|---|
```

## 비교표 형식

```text
| 기준 | A | B | 판단 |
|---|---|---|---|
```

## 로컬 폴더 조사 형식

```text
폴더 성격:
먼저 읽은 파일:
읽지 않은 파일/영역:
핵심 구조:
작동 방식:
주의할 경계:
다음 읽기 경로:
```

## decision brief 형식

```text
결론:
선택 기준:
근거:
리스크:
보류 조건:
다음 행동:
```

## 출력 규칙

- 먼저 결론을 준다.
- 근거와 해석을 섞지 않는다.
- 모르는 것은 모른다고 쓴다.
- 큰 자료를 다 읽지 않았으면 읽지 않은 범위를 밝힌다.
- 최신성이 필요한 정보는 확인 날짜나 출처 날짜를 남긴다.
- 출처 충돌이 있으면 충돌을 별도 항목으로 둔다.
- 사용자가 요청하지 않은 장황한 배경 설명을 줄인다.
- 다음 행동은 실제로 할 수 있는 단위로 쓴다.
