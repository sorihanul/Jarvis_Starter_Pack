# Runtime Boundary

## role

Coding_TOML_Agent_Brain manages bounded coding tasks in one thread.

It creates temporary TOML role contracts when useful.
It does not create separate sub-brain threads.

## inside boundary

```text
task intake
single-thread suitability decision
TOML role draft
agent sequence planning
code work coordination
verification gate
release boundary check
memory export draft
```

## outside boundary

```text
multi-thread project management
global brain design
central canon mutation
automatic commit push or PR
large independent frontend/backend/design delegation
```

## escalation

If the task needs independent role threads, hand off to `Coding_Meta_Brain`.
