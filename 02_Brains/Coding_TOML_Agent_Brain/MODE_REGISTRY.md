# Mode Registry

## modes

### intake_mode

Bind the task, target project, repo source, task type, and acceptance condition.

### solo_suitability_mode

Decide whether the task can stay in one thread.

### agent_draft_mode

Draft temporary TOML role agents in `AGENTS/ACTIVE/` only if the task needs them.

### agent_sequence_mode

Order active agents for sequential execution.

### code_work_mode

Perform code work according to scope and active agent contracts.

### verification_gate_mode

Run or interpret required verification.

### closeout_mode

Write final report, archive agent contracts, and draft memory export.
