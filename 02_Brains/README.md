# Reference Sub-Brains

## purpose

`02_Brains/` contains optional dormant reference sub-brains for Jarvis Starter Pack v3.

These brains are documents until a user explicitly boots one. They are not part of the core boot path and are not required for basic v3 use.

## included brains

- `Info_Research_Brain/`: source-first research brain.
- `Jarvis_Verification_Brain/`: validation and proof brain.
- `Ontology_Builder_Design_Brain/`: design brain for producing domain ontology brains and ontology projects.

## experimental sub-brains

- `Coding_Meta_Brain/`: experimental coding Chief brain for case-scoped coding workspaces. Treat as `runtime_validated:false`, `reference_ready:false` until it is tested on a real larger coding project.
- `Coding_TOML_Agent_Brain/`: experimental single-thread coding harness that drafts TOML role agents only when a bounded coding task needs them. Treat as `runtime_validated:false`, `reference_ready:false` until it is tested against real solo-thread coding cases.

## public wording

The coding sub-brains are public as document harness experiments.
They are not validated coding runtimes.

Use these phrases:

```text
experimental static-ready coding harness
document-first AI coding workflow template
runtime_validated:false
reference_ready:false
not real-project validated yet
```

Do not claim:

```text
stable coding runtime
validated coding agent
production-ready automation
guaranteed secure code generation
```

Promotion from `reference_ready:false` requires real project evidence in the corresponding `REPORTS/` files.

## use

Open the brain folder and read its `README.md` first.
Then continue to `START_HERE.md`, or boot with the brain's launch phrase when one is defined.

## rule

Do not treat every reference brain as required. Use only the brain that matches the current task.
