# External Research Rule

## rule

For non-developer owners, external research is part of coding intake.

Do not rely only on internal average guessing when the task needs technology, product pattern, security, deployment, or dependency choices.

## required when

```text
new_app_or_tool:true
new_framework_or_library:true
auth_payment_personal_data:true
file_upload_or_public_deploy:true
package_addition:true
unknown_domain_workflow:true
```

## preferred sources

```text
official_docs
framework_security_docs
package_registry
maintainer_repository
deployment_provider_docs
OWASP_or_security_guides
well_known_product_patterns
```

## output

```text
research_questions:
sources_checked:
recommended_boring_path:
rejected_options:
security_notes:
dependency_notes:
deployment_notes:
unknowns:
impact_on_final_goal:
```
