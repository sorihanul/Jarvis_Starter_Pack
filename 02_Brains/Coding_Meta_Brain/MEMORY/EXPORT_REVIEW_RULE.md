# Export Review Rule

## review rule

Memory export is input to central review.
It is not canon.

## accept only

```text
reusable_coding_principle
repeated_failure_pattern
verification_improvement
sub_brain_selection_improvement
publish_boundary_improvement
```

## reject

```text
secret
private_repo_detail
raw_log
unverified_guess
one_time_workaround
```
