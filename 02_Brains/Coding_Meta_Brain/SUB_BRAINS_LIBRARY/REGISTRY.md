# Sub-Brain Registry

## Repo_Intake_Brain

```text
use_when: new repo or unfamiliar project
output: repo map, scripts, tests, local rules, risk notes
```

## Frontend_Brain

```text
use_when: UI, state, responsiveness, accessibility, visual behavior
output: frontend implementation report and UI verification needs
```

## Backend_Brain

```text
use_when: API, database, auth, jobs, service logic, server errors
output: backend implementation report and contract notes
```

## Design_Brain

```text
use_when: layout, UX, design system, component polish, visual consistency
output: design constraints and UI quality review
```

## Integration_Brain

```text
use_when: frontend-backend contract, env/config, cross-module behavior
output: integration contract report
```

## Verification_Brain

```text
use_when: lint, tests, build, typecheck, screenshot, smoke, failure triage
output: verification report and failure interpretation
```

## Release_Gate_Brain

```text
use_when: publish, package, deploy, GitHub release, final handoff
output: release boundary report
```
