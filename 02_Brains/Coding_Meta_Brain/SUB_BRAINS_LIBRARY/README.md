# Sub-Brains Library

## purpose

This folder contains selectable sample sub-brain roles for coding cases.

They are library parts.
They are not active until Coding_Meta_Brain selects them for a case.

## included samples

```text
Repo_Intake_Brain
Frontend_Brain
Backend_Brain
Design_Brain
Integration_Brain
Verification_Brain
Release_Gate_Brain
```

## rule

Do not copy every sub-brain into the active thread plan.
Select only the roles that reduce risk for the current case.
