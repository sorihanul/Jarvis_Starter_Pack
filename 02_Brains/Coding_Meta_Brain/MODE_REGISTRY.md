# Mode Registry

## modes

### intake_mode

Use for binding the coding case, project surface, repo source, task type, and risk.

### coordination_mode

Use for selecting sub-brain roles and opening thread handoffs.

### implementation_watch_mode

Use while implementation threads are active.
The meta brain tracks scope, reports, and blockers.

### verification_gate_mode

Use when changed code must be checked through lint, tests, build, typecheck, screenshot, smoke, or manual review.

### release_boundary_mode

Use before publishing or packaging.
Confirm only `01_PROJECT/` or its intended build output is released.

### memory_export_mode

Use at closeout to draft reusable lessons for central review.
