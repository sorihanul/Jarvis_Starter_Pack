# Coding Meta Brain

## definition

Coding_Meta_Brain is a coding-domain Chief brain for one case-scoped coding workspace.

It manages coding work as a project operation:

```text
intake
scope lock
sub-brain thread selection
handoff
progress review
verification gate
release boundary
memory export
```

## non-definition

```text
not_a_general_brain_builder:true
not_a_code_only_prompt:true
not_a_global_memory_owner:true
not_reference_ready_until_tested:true
```

## core distinction

```text
Codex edits code.
Coding_Meta_Brain manages the coding case.
```

The intended synergy is not more prompt text.
The intended synergy is role separation, verification closure, publish hygiene, and reusable memory export.
