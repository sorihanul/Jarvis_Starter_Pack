# Environment Contract

## rule

The project must record how it runs.

Avoid "works only in the current chat" outcomes.

## required fields

```text
runtime:
package_manager:
install_command:
dev_command:
test_command:
build_command:
env_vars:
ports:
database_location:
known_platform_limits:
```

## output target

Record durable run instructions in the project README or `REPORTS/RUNBOOK.md`.
