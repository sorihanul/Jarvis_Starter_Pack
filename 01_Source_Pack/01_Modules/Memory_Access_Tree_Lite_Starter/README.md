# Memory Access Tree Lite Starter

## 목적

`Memory Access Tree Lite`는 자비스가 저장된 기억 전체를 다시 읽지 않고, 이번 작업에 필요한 파일 후보만 고르도록 돕는 선택형 기억 접근 지도다.

이 모듈은 새 메모리 저장소가 아니다.
이미 있는 `TASKS`, `LOGS`, `CAPSULES`, `03_Memory`, 위키, 스킬, 프로젝트 문서 중 무엇을 다시 확인할지 정하는 얇은 지도다.

## 언제 쓰나

- 같은 주제에서 매번 어떤 파일을 다시 읽어야 할지 다시 정해야 할 때
- 파일, 로그, 캡슐, 프로젝트 문서가 늘어나 세션 복귀 속도가 느려질 때
- 특정 주제와 연결된 파일 후보를 2~4개로 줄여야 할 때
- 오래된 연결, 약한 연결, 나중에 만들 기억 자리를 따로 표시해야 할 때

## 무엇이 아닌가

- `MAP.md` 대체품이 아니다.
- 위키 본문 저장소가 아니다.
- 전체 폴더 요약문이 아니다.
- 자동 검색 엔진이 아니다.
- 이번 작업의 실제 읽기 순서를 강제하는 실행 라우트가 아니다.

## 한 줄 원칙

`MAP.md`가 위치를 알려준다면, `Memory Access Tree Lite`는 특정 주제에서 어떤 파일을 다시 확인하고 어떤 파일은 확인하지 않을지 정한다.
