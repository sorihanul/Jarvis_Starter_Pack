# Basic Function + Cognitive Function Concept v0.1

## Core idea
The AILO function system has two layers:

```text
basic function = common layer
cognitive function = expansion layer
```

The basic function layer stabilizes the control surface.
The cognitive function layer performs meaning work when simple control is not enough.

Do not merge them.

## AILO as function source
AILO is the material for making functions.
It is an open gateway for generating new function candidates.

The current basic functions are not the limit of AILO.
They are the first common control contracts.

New function ideas should enter through a candidate gate before they become part of the common layer.

## Common layer rule
Basic function is the common layer.
Cognitive function is the expansion.

```text
basic runtime route
-> basic function

cognitive route
-> basic function
-> cognitive function
```

So the basic function layer is not a v2-only layer and not a separate starter set.
It is the common lower contract layer.

Cognitive functions are added only when the work crosses into meaning, judgment, lens, or brain-local reasoning.

## Basic function
A basic function is a small callable contract for control hygiene.

It answers questions like:

```text
What is the requested scope?
Which route should be read first?
Which slot is missing?
Which output schema must be used?
Is memory writing allowed?
What trace level is required?
What gate label applies?
```

It should be:
- small
- low cost
- repeatable
- schema-bound
- mostly pure

Basic functions should not perform deep interpretation.

## Cognitive function
A cognitive function is a callable thought operation.

It answers questions like:

```text
What hidden premise is driving this request?
What meaning is missing from the visible text?
Which evidence has authority?
Which lens should be used?
Which contradiction matters?
What reading posture should the brain take?
```

It may use:
- cognitive schema
- ST/S-T patterns
- evidence comparison
- domain lens
- brain-local rules

Cognitive functions are heavier than basic functions.

## Relationship
The basic function layer prepares clean input.
The cognitive function layer reads and transforms meaning.

```text
user language
-> basic functions
-> cognitive functions when needed
-> skill / brain / engine
```

Basic functions are the lower contract layer.
Cognitive functions are the higher interpretation layer.

## Rule of separation
Keep an operation in the basic layer when it only:
- normalizes slots
- selects a route
- binds a schema
- checks policy
- labels a gate
- prepares trace

Move an operation into the cognitive layer when it:
- judges meaning
- restores an unstated premise
- compares evidence quality
- applies a cognitive schema
- changes reading posture
- becomes local to a specialized brain

## First implementation order
Start with the basic function layer.

```text
basic function
-> common control proof
```

Then expand into cognitive functions through a bridge.

```text
basic function system
-> cognitive expansion bridge
-> cognitive function system
```

Do not start by building the full cognitive library.

## One-line rule
Basic function is the common control layer; cognitive function is the meaning expansion layer.
