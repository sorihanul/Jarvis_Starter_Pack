# Function to Cognitive Expansion Bridge v0.1

## Purpose
This bridge explains how the basic AILO function system expands into the AILO cognitive function system.

Do not merge the two layers.
Expand from one to the other only when the operation changes from control hygiene to meaning work.

In short:

```text
basic function
-> cognitive function
```

The basic function layer is shared.
Cognitive functions are an expansion, not a replacement.

## Base layer
The base layer is:

```text
AILO E++ based AILO function system
```

It handles:
- slot normalization
- route selection
- output schema binding
- side-effect policy
- trace policy
- permission labeling

## Expansion layer
The expansion layer is:

```text
AILO cognitive expansion based AILO cognitive function system
```

It handles:
- meaning judgment
- hidden premise recovery
- evidence authority comparison
- contradiction split
- lens extraction
- ST/S-T schema use
- brain-local reasoning moves

## Expansion trigger
Expand a function into a cognitive function only when at least one is true:

```text
the operation judges meaning
the operation recovers unstated assumptions
the operation compares evidence quality
the operation applies an ST/S-T schema to interpret content
the operation changes the model's reading posture
the operation becomes brain-local
```

## ST/S-T relation
ST Dictionary and S/T aliases are not the same as cognitive functions.

They are lower-level schema builders.

```text
ST Dictionary
-> cognitive schema source

S/T alias function
-> schema object builder

AILO cognitive function
-> thought operation that uses schema objects to read, judge, or transform meaning
```

## Example

```text
route_lock
-> AILO function
```

Reason:
- chooses a route
- uses explicit inputs
- does not judge hidden meaning deeply

```text
source_role_judgment
-> AILO cognitive function
```

Reason:
- judges what a source is for
- may use S3 Path, S4 Link, S22 Standard, S37 Uncertainty
- changes reading posture

## One-line rule
AILO functions stabilize control; AILO cognitive functions use schemas to perform meaning work.
