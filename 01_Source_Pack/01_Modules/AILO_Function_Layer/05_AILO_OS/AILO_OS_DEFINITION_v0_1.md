# AILO OS Definition v0.1

## Definition
AILO OS is not a document.

It is an AI work operating layer that turns intent, slots, functions, skills, engines, memory, trace, permission, and packaging into an executable or reproducible workflow.

## What it manages

```text
natural language input
-> AILO intent
-> slot normalization
-> function call
-> skill run
-> engine pipeline
-> optional agent/tool call
-> validation
-> trace
-> memory candidate
-> package or release
```

## Layer position

```text
AILO function
  smallest operation

AILO cognitive function
  bounded thought operation

AILO engine
  ordered and verified execution structure

AILO OS
  operating layer that runs, records, validates, governs, and packages them
```

## Not this
AILO OS is not:
- a prompt collection
- a markdown-only starter
- a brain card
- a skill list
- a workflow diagram
- an agent persona

Those can describe or feed AILO OS.
They are not AILO OS by themselves.

## Minimum components
AILO OS begins only when these exist as runnable or reproducible surfaces:

```text
parser
registry
function runner
skill runner
engine runner
permission policy
validation gate
trace surface
memory side-effect policy
release or package surface
```

## Relationship to Jarvis v2
Jarvis v2 is a document harness.

It can teach a host model how to behave.
It can guide file reading, route selection, memory surfaces, and option pack usage.

But it is still document-first.

AILO OS starts when the behavior is no longer only described by documents and is instead run by a stable operating surface.

## Relationship to cognitive expansion
The cognitive expansion lane is the source and research lane for cognitive functionization and engine compilation.

AILO OS is the execution ambition above that lane.

The expansion lane can produce:
- functions
- cognitive functions
- engines
- packaging rules
- runtime contracts

AILO OS runs those parts through a stable operating layer.

## One-line rule
AILO OS is the point where AILO stops being only a document language and becomes an operating layer for AI work.
