# AILO Function Material Gateway v0.1

## Core idea
AILO is function-making material.

AILO is also an open gateway for making new functions.

The seven basic functions are not the whole function universe.
They are the first common control set.

## What AILO provides
AILO provides material for making functions from:

```text
intent slots
verbs
rules
guards
risk labels
memory policy
trace policy
output contracts
stop rules
validation gates
```

Any repeated control move can become a function candidate.

## Infinite gateway rule
The gateway is open.
The common layer is controlled.

```text
AILO material
-> function candidate
-> candidate gate
-> basic function or cognitive function
```

Do not confuse infinite function potential with uncontrolled function promotion.

## Basic function lane
Use the basic function lane when the candidate mainly controls:

```text
scope
route
missing slots
output shape
memory side effect
trace weight
permission gate
```

## Cognitive function lane
Use the cognitive function lane when the candidate mainly performs:

```text
meaning judgment
hidden premise recovery
evidence comparison
domain lens use
brain-local reading posture
```

## Candidate rule
New function ideas should first become candidates.

They should not be added directly to the common layer.

Candidate record:

```text
candidate_name
source_need
input_slots
expected_output
why_existing_functions_are_not_enough
basic_or_cognitive
promotion_condition
```

## Promotion rule
A candidate may become a basic function only when:

```text
it is repeated
it is control-facing
it is smaller than a skill
it does not judge meaning
it has stable input and output
it cannot be handled by the existing seven functions
```

## One-line rule
AILO can generate endlessly, but the common function layer admits only proven control contracts.
