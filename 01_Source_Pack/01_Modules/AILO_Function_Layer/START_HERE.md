## Use when
- classifying a new AILO operation
- deciding whether a rule belongs to the basic public layer or the cognitive expansion layer
- deciding whether a function bundle should become a skill
- deciding whether a skill/function bundle should become an engine
- deciding whether related functions should remain a function pack
- deciding whether something is still a document/spec or has crossed into OS/runtime territory
- checking the development order before implementing anything
- planting the base AILO function system before expanding into cognitive functions
- checking whether function packs can manufacture a skill skeleton before building cognitive functions
- rerunning skill-manufacturing proof samples before promoting v0.2 functions
- checking whether v0.2 skill-skeleton functions are stable candidates, not stable functions

## Do not use when
- you only need promoted public source rules
- you only need raw bank material
- you are writing work logs

## One-line rule
Start with functions, group related actions into function packs, and promote the pack group only when it needs to become an engine, skill, or brain component.
