# 00 Beginner Quick Start

## One Sentence

This pack helps you decide which brain to read, whether to work in the current thread, whether to create a handoff for another thread, and how to integrate the returned result.

The beginner-safe name for the main idea is `brain lens`.

```text
brain lens:
  temporarily read and apply another brain's rules for one bounded task
```

## Do Not Misread This Pack

This pack does not make one brain control another brain.

Use this mental model:

```text
wrong:
  parent brain controls sub-brains

right:
  main brain chooses a brain route
  main brain reads the needed brain files
  main brain applies that brain as a temporary lens
  or main brain writes a launch prompt for another thread
  main brain later integrates the returned output
```

## The Three Choices

Before using this pack, choose only one mode.

```text
same_thread_lens:
  read another brain's entry files and use that lens in this thread

separate_thread_handoff:
  write a launch prompt for another thread or agent

integration_only:
  read outputs that already exist and combine them
```

## Minimal Use

For beginners, do not create a large structure first.

Start with this:

```text
selected_brain:
mode:
entry_files:
task:
expected_output:
return_condition:
```

Create full route files only when this will repeat.

## When It Is Useful

```text
you are unsure which brain should handle the task
you need to hand work to another thread
you have outputs from several specialists
you need a release or verification gate
you need to keep the original thread as the final decision owner
```

## When It Is Too Much

```text
one short answer is enough
one file needs a simple edit
one domain brain already owns the task
no separate handoff is needed
no returned output must be integrated
```

## Beginner Safe Prompt

```text
Read this pack only to choose the correct brain route.
Do not claim that one brain can control another brain.
Decide whether this is same-thread lens, separate-thread handoff, or integration-only.
If same-thread, list the entry files to read.
If separate-thread, write a launch prompt.
If integration-only, list the outputs to compare and how to close.
```
