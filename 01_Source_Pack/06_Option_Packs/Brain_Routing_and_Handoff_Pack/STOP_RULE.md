# Stop Rule

Stop using this pack when:

```text
one brain can complete the task
no handoff is needed
no returned output must be integrated
route surfaces add more work than clarity
the active route is obvious and will not repeat
the model starts pretending it can control another brain
```

## Use A Smaller Pack Instead

If the task only needs a checklist, use `Verification_and_Proof_Pack`.

If the task only needs file reading order, use `Memory_Access_and_Route_Pack`.

If the task only needs external source intake, use `Evidence_Intake_Pack`.

Use `Brain_Routing_and_Handoff_Pack` only when brain route, handoff, or integration is the actual problem.
