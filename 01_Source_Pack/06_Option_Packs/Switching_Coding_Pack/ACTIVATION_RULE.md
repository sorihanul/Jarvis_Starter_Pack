# Activation Rule

## Activate

Activate `Switching_Coding_Pack` when the task is coding-related and role separation will reduce mistakes.

Use it for:

```text
small implementation with scope control
bug fix with reproduction and verification
code review before patching
test repair or test plan
refactor boundary check
release summary after code changes
separate coding or review handoff prompt
```

## Do Not Activate

Do not activate it when:

```text
the user asks a simple coding question
the answer is one explanation and no file/action is needed
the repository already has a stronger local coding harness
the task is not about code, tests, build, CI, or code release
the pack would add ceremony without reducing risk
```

## Default

The default lens is `intake lens`.

Move to another lens only after the goal, scope, success criteria, and no-go areas are clear.
