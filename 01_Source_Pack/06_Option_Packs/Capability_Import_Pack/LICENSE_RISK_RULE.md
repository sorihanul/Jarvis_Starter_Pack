# License Risk Rule v0.1

## 목적

외부 자료를 자비스 능력으로 바꿀 때 라이선스 위험을 줄인다.

## 기본 원칙

- 코드 직접 복사는 하지 않는다.
- 고유 문구를 그대로 가져오지 않는다.
- 파일 구조를 그대로 재현하지 않는다.
- 강한 copyleft 라이선스는 특히 조심한다.
- 공개 자료에서 배운 점은 일반적인 설계 원칙으로 다시 쓴다.

## 위험 등급

```text
low:
  일반 아이디어, 공개적으로 흔한 패턴, 짧은 사실 요약

medium:
  프로젝트 고유 구조와 명칭을 많이 따라가는 경우
  문서 문구를 길게 따라가는 경우

high:
  코드 복사
  테스트 복사
  고유 알고리즘 구현 복사
  라이선스가 강한 저장소의 구현을 그대로 반입
```

## 자비스 적용 규칙

외부 프로젝트가 유용해도 자비스에는 아래 형태로만 반영한다.

```text
능력 이름
활성 조건
입력 슬롯
금지 조건
산출물
검증 기준
```

## 표시

외부 자료를 분석한 경우에는 작업 로그나 자료 분석 노트에 출처와 라이선스를 적는다.

단, 자비스 내부 규칙은 독립적으로 이해되게 다시 쓴다.
