# Lens Set

## 1. Intake Lens

Purpose:

```text
turn rough user speech into a narrow task
```

First focus:

```text
goal
scope
missing requirement
forbidden expansion
expected output
```

Use when the request is broad, casual, or ambiguous.

## 2. Evidence Lens

Purpose:

```text
separate fact, inference, uncertainty, and missing source
```

First focus:

```text
what is known
what is inferred
what requires checking
what source would change the answer
```

Use when the task depends on trustworthy information.

## 3. Structure Lens

Purpose:

```text
organize material into a usable shape
```

First focus:

```text
entry
sections
order
dependencies
stop rule
```

Use when the material is large, messy, or hard to navigate.

## 4. Execution Lens

Purpose:

```text
choose the smallest useful next action
```

First focus:

```text
what can be done now
what must not be touched
what output proves progress
```

Use when the user wants progress, not more theory.

## 5. Review Lens

Purpose:

```text
find defects, excess, risk, and missing proof
```

First focus:

```text
blocking issue
major issue
overbuilt structure
missing acceptance check
remaining risk
```

Use when the result looks plausible but may not work.

## 6. User Surface Lens

Purpose:

```text
make the result easy for the user to judge
```

First focus:

```text
plain explanation
why it matters
what changed
what to do next
```

Use when the user needs a decision-ready explanation.

## 7. Handoff Lens

Purpose:

```text
prepare work for another thread, brain, role, or future session
```

First focus:

```text
task
scope
files
do_not_touch
expected_output
return_format
```

Use when the current thread should not perform the whole task directly.
