# Operating Rule

## Standard Loop

```text
1. restate the task goal
2. choose one active lens
3. state why this lens is needed
4. state what the lens sees first
5. state what the lens will not expand into
6. decide whether a skill or option pack is needed
7. perform the lens pass
8. return to the main task
```

## Single-Lens Default

Use one lens by default.

Do not chain lenses unless the task clearly needs it.

## Lens Chain

Allowed short chain:

```text
intake -> execution -> review -> user_surface
```

Allowed evidence chain:

```text
intake -> evidence -> structure -> user_surface
```

Allowed handoff chain:

```text
intake -> handoff -> review
```

## Forbidden Drift

Do not let lens switching become:

```text
roleplay
personality simulation
multi-agent theater
unbounded brainstorming
skill replacement
new brain creation
```

## Reporting Rule

If the lens pass changes the answer, say what changed.

If it does not change the answer, say that the original answer survives the lens check.
