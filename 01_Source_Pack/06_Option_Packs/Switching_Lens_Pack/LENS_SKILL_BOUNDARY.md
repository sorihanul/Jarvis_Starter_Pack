# Lens / Skill Boundary

## One Line Difference

```text
lens = how to see the task
skill = how to perform a repeatable move
```

## Lens Owns

```text
what to notice first
what to ignore
what risk to watch
what output surface is appropriate
when to stop
which skill should be used, if any
```

## Skill Owns

```text
checklist
script
template
search procedure
rewrite procedure
verification procedure
formatting procedure
```

## Good Pairing

```text
intake lens
-> no skill, if the task only needs clarification

evidence lens
-> research/source-check skill

structure lens
-> outline/wiki/route-building skill

execution lens
-> task-specific procedure skill

review lens
-> verification/security/checklist skill

user_surface lens
-> writing/briefing skill

handoff lens
-> launch prompt or handoff template
```

## Bad Pairing

```text
using a skill before deciding what lens is needed
using lens switching as a replacement for a real procedure
using one skill result as final output without review
opening many skills because the lens is unclear
```

## Decision Rule

```text
If the problem is confusion of posture, switch lens.
If the problem is missing procedure, use skill.
If both are needed, lens comes first.
```
