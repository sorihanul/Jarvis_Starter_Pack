# Canon Memory Candidates

## 목적

대화, 캡슐, 작업 로그에서 뽑은 위키 후보를 임시로 둔다.

후보는 정본이 아니다.
다음 세션이나 사용자가 확인하기 전까지는 운영 규칙처럼 쓰지 않는다.

## 후보 형식

```text
# Candidate: <title>

## source

- from:
- date:

## candidate_type

decision | rule | how_to | failure_pattern | glossary | concept

## content

짧은 정리.

## promotion_condition

무엇이 확인되면 WIKI로 올릴 수 있는가.
```
