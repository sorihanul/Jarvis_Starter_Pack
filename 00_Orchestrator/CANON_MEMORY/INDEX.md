# Canon Memory Index

## 목적

정본 위키 항목의 짧은 연결과 읽기 조건을 남긴다.

본문은 `WIKI/`에 두고, 아직 정본이 아닌 것은 `CANDIDATES/`에 둔다.
작업별 읽기 경로가 필요하면 `ROUTES/INDEX.md`를 먼저 본다.

## 항목 형식

```text
- title:
  file:
  type:
  status:
  confidence:
  read_when:
  do_not_read_when:
  scope:
  supersedes:
  superseded_by:
  related:
  conflict_check:
  last_reviewed:
```

## 현재 항목

아직 등록된 정본 위키 항목이 없다.
