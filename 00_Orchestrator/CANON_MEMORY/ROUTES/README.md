# Canon Memory Routes

## 목적

정본 위키 전체를 읽지 않고, 현재 작업에 필요한 정본 노트만 고르기 위한 경로면이다.

## 원칙

- `INDEX.md`를 먼저 본다.
- `WIKI/` 전체를 기본으로 읽지 않는다.
- 읽기 조건이 뚜렷하지 않은 정본은 route에 올리지 않는다.
- route가 길어지면 주제별 route 파일로 나눈다.
- `status: deprecated` 항목은 기본 route에서 제외한다.
- `conflict_check: unresolved` 항목은 결론 근거가 아니라 확인 대상으로 둔다.
