# Canon Memory Route Index

## 목적

정본 위키 항목을 언제 읽을지 정한다.

이 파일은 Canon Memory의 기본 진입면이다.
본문은 `../WIKI/`에 있고, 후보는 `../CANDIDATES/`에 있다.

## 항목 형식

```text
- title:
  file:
  status:
  confidence:
  read_when:
  do_not_read_when:
  scope:
  supersedes:
  superseded_by:
  related:
  conflict_check:
  last_reviewed:
```

## 현재 항목

아직 등록된 정본 route 항목이 없다.
