# Orchestrator

이 폴더는 자비스 스타터의 실제 부팅 지점이다.

처음 사용하는 사람은 `Jarvis_Main_Brain/BOOT.md`를 읽히고 메인 브레인을 부팅한다.

## 포함 항목

- `LOCAL_RULEBOOK.md`
  - 이 오케스트레이터의 로컬 운용 규칙
- `MEMORY_MAP.md`
  - 무엇을 정체성, 길찾기, 세션, 원천소스로 볼지 나누는 지도
- `SESSION_CARD.md`
  - 새 세션 재진입용 정체성 카드
- `Jarvis_Main_Brain/`
  - 자연어 요청을 AILO식 의도 슬롯으로 좁혀 실행 구조로 바꾸는 메인 브레인
  - 문답, 리서치, 글쓰기, 코딩, 계획, 검증, 보안, 학습, 브레인/스킬/프로젝트 설계를 맡는다
- `TASKS/`
  - 현재 작업 상태와 브레인/프로젝트 요청을 둔다
- `LOGS/`
  - 세션 운영 기록을 둔다
- `CAPSULES/`
  - 다음 세션 인수인계 요약을 둔다

## 원칙

- 원천소스는 `01_Source_Pack`에서 읽는다.
- 원천소스를 작업장처럼 수정하지 않는다.
- 현재 오케스트레이터 기록은 이 폴더의 `TASKS`, `LOGS`, `CAPSULES`에 둔다.
- 새 브레인이나 프로젝트는 메인 브레인이 별도 폴더로 설계한다.
- 사용자가 긴 양식을 몰라도 되게 목적, 범위, 금지, 산출물을 먼저 좁힌다.
- AILO는 의도 제어층으로 사용하고, 사용자가 직접 문법을 쓰게 하지 않는다.
